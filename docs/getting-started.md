# Getting started

[← Back to the README](../README.md)

## Set up search (a free TMDB key)

Search, title pages and the suggestion rows use a free key from TMDB (themoviedb.org). Choose **Set up search** on Home (it takes you straight to the right place in Settings), or open **Settings** (the gear at the top right) → General → Search, and pick one:

- **Paste it from my phone:** scan the code and paste your key on the page that opens. It has a link to TMDB's API settings, so you can copy the key there first.
- **Find it on themoviedb.org:** opens TMDB's API settings in the app. Sign in, copy the **API Read Access Token** (the long one), then press Start and pick *Back to settings*. The copied key is picked up for you. If copying doesn't work, *Use the key on this page* in the same menu reads it off the page.
- **Use copied key:** if it's already copied.

## Getting around

**L1 / R1** switch between the tabs at the top of the home screen:

- **Home:** your rows. **Jump back in** (what you're partway through on Jellyfin and Plex), **Up next**, **Inspired by what you've watched**, then **Trending** and what's popular on your services. The selected title fills the top of the screen with its picture and where you can watch it. **More**, at the end of a row, opens the whole list.
- **Live:** live TV channels and their guide. See [Live TV](live-tv.md).
- **Genres:** the usual genres, plus **See all genres** for 50-odd more (holidays, superheroes, anime, K-dramas, the '80s…).
- **Music:** see [Music and radio](music.md).
- **Library:** everything on your server, A to Z. The letter bar on the left jumps to a letter.

Pick a title to see which of your services streams it. Your own servers always come first.

How the rows are laid out (Netflix-style, plain rows, a grid, PS5, PS3) is up to you: see [Themes](themes.md).

## Controls

These are the defaults. Change any of them in **Settings → Controller**.

| Button | Does |
|---|---|
| D-pad / left stick | Move around |
| A | Select |
| B | Back (on websites, a page back; the menu when there's nothing left) |
| Start | Open or close the menu (F10 on a keyboard) |
| Select | Leave full screen on websites |
| R3 | On-screen keyboard on websites (A on a text box works too) |
| Y | Play / pause; a space when typing |
| X | Delete a letter |
| Right stick | Move the pointer on websites |
| R2 / L2 | Click / right-click at the pointer |
| R1 / L1 | Scroll on websites; switch tabs in the app |

A keyboard works everywhere too. **Quit SOFA King** is the last item in the menu (it asks first). You sign in to each streaming service once; it's remembered.

## Settings

Settings has tabs across the top (**L1 / R1** switch them), each with its sections down the left. Right goes into a section, Left comes back out. Settings reopens where you left it.

While watching something, **Start** opens the menu, which has Settings. Settings opened there sits over your show: **B** steps back out, and **Start** closes everything at once.
